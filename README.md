# Bellamie Keyboard (Android)

Android Input Method Editor (IME) implementing the supplied English/Kurdish keyboard layout.

## Build

Open this repository in Android Studio and let Gradle sync. Build the `app` module to create the APK.

## Enable the keyboard

Install the app, open Android Settings → System → Languages & input → On-screen keyboard → Manage on-screen keyboards, enable **Bellamie Keyboard**, then select it as the active keyboard.

The keyboard is not enabled automatically; Android requires the user to enable and select an IME.
